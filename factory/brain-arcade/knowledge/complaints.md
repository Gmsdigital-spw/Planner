# What teachers complain about (reviews and blogs) and how we avoid it

| Seen | Complaint | Source | Our rule |
|---|---|---|---|
| 2026-10-25 | Wrong answers in the key | (Grayson's rule) | tools/answer_check.py must PASS; a wrong answer is an automatic fail |
| 2026-10-25 | Answer key gave the wrong letter / missing answers in a gingerbread escape room | twinkl.com.ph review | answer_check.py also checks code-word letters |
| 2026-10-25 | Couldn't contact the seller about a clue error | tes.com review | terms page: "Message us on Etsy and we will help right away" |
| 2026-10-25 | Paper escape rooms take long to prep (cutting, hiding clues) | ahaslides.com blog | no-cut design: one page per lock, recording sheet |
| 2026-10-25 | Single-use pages = reprinting every class | escaperoomgeeks.com | recording sheet lets lock pages be reused/laminated (say so in copy when true) |
| 2026-10-25 | Ink cost | saddleupfor2ndgrade.com | offer a low-ink version when the type allows |
| 2026-10-25 | Timers make it stressful; some tasks too hard | PMC8305373 study | timer optional in teacher guide; grade-fit check |
| 2026-10-25 | Wide or missing grade labels (Gr 3-6, ages) | Etsy search snippets | every product names ONE grade (or a 2-grade band) and its standards |

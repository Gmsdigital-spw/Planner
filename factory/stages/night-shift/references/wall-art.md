## Scout
- Scout (step 2): one of the 3 briefs each run is a wall art set (niche "wall art", 4 to 6 prints that belong together). The "text-based printables only / no art-heavy products" line does not apply to it; buildable means it can be made well with the kit's backgrounds (stripes, thinstripes, gingham, check, solid, leopard, hydrangea, ditsy), frames (cameo, arch, ribbon, none), motifs (bow, tulips, heart, cherries, hydrangea, star) and fonts (script, serif, caps). Themes she likes: pink coquette Christian verse sets, Christian Christmas verse sets (in season now), pink leopard and bows ("lucky girl", cherries), powder blue trendy dorm prints, girls' playroom affirmation sets (original phrases), grandmillennial hydrangea and stripes, soft nursery sets. Research the top wall art listings for the theme with WebSearch and record real evidence links like any brief.

## Words and originality
- Words on prints: Bible verses in the King James Version ONLY (public domain). NIV, ESV, NLT, NKJV, CSB and other modern translations are copyrighted and never used. Copy each verse's exact KJV wording from a real KJV page you opened, keep the source url in product.notes, and use the true reference (book chapter:verse). Other phrases must be short and original or common everyday sayings; never song lyrics, poems, quotes from famous people, slogans or brand taglines.
- Never: designer or fashion brand names or logos (Prada, Chanel or "Coco", Dior, Gucci and the like), Disney-like princesses, castles, carriages, glass slippers or anything that echoes a film, characters, famous paintings or parodies of them, sports teams, or anything copied from another shop. The auto-approver rejects these.

## Auto-approver
- Auto-approver (step 2c): judge a wall art brief by the same rules except buildable (above). Approve at most 1 wall art brief per run. If a wall art brief qualifies it may use one of the buildsPerRun slots.

## Forge
- Forge (step 4): write each print as wa.design(bg, frame, motif, lines, ref, font, palette) with an art palette from wa.ART_PALETTES (blush, rosebud, leopard, powder, sage, butter, lavender, berry). A set looks like it belongs together: one or two related palettes, the same motif family, and a mix of 2 or 3 backgrounds and frames so the prints are not copies of each other; include one or two prints with no words (motif only, motif_pos "center") when it suits the theme. Render every print at 150 dpi with wa.render(d, 8, 10, dpi=150), put them in one contact sheet and Read it yourself: fix any crowded words, awkward line breaks or clashing colours. Then build the full file with wa.export_pdf(designs, path, title, limit_mb=60): a how-to-print page, then every print at 8x10, 11x14 and 12x18, each drawn natively at 300 dpi. The Starship can only send files under about 600 KB to Etsy, so the full file is hosted on Grayson's GitHub Pages site and the Etsy file is a small download-link PDF (set up with Grayson on Oct 19, 2026): (a) the repo Gmsdigital-spw/Planner is ALREADY cloned at /home/claude/planner when your run starts (check: git -C /home/claude/planner remote -v); cd there and git pull --rebase; (b) only if that folder is missing, git clone --depth 1 https://github.com/Gmsdigital-spw/Planner there (generous timeout); do NOT use add_repo (it is not available in scheduled runs); if a push fails with 403, follow the "Waiting on GitHub hosting" rule below and tell Grayson "GitHub access needs a look" in one line; (c) copy the full PDF to prints/<16 random hex chars from secrets.token_hex(8)>/<product slug>.pdf, git config user.email noreply@anthropic.com and user.name Claude, commit with a short message, fetch and rebase on origin main, push; (d) the url is https://gmsdigital-spw.github.io/Planner/prints/<hex>/<slug>.pdf (capital P); wait about a minute and confirm it loads with WebFetch, retrying a few times over 3 minutes; (e) build the Etsy file with wa.link_pdf(local path, title, url, [wa.render(d, 8, 10, dpi=40) for d in designs], "8x10, 11x14 and 12x18", number of prints) (it raises if over 550 KB) and upload THAT as product.file (pages 1, kind "download-link"); save product.fullFile {hostedUrl, pages, sizeBytes, and assetId when the full PDF is under 15 MB and uploads as an asset}. If adding the repo or pushing fails, or the url never loads, do not batch the product: set stage "sentback" with a note "Waiting on GitHub hosting: <the error>" so the next run retries, and put it in the report's NEEDS YOU line. Never put the full PDF in product.file. Save product.kind "wallart", product.prints (the design dicts) and product.style {palette (the art palette), mpal (the gs palette used for photos: blush, berry, sage or another warm one), layout "flatlay", desk, kit "wall_art_v1"}.

## Quill
- Quill (step 5): category "Art & Collectibles > Prints > Digital Prints"; materials "Digital download, PDF". The description names every print (each verse with its reference, or each phrase), the sizes included, says the buyer receives a PDF with a link to download the full-size print files, how to print (100% / actual size, cardstock or photo paper, or any print shop), says no frame or physical item ships and that it is for personal use, and ends with the exact AI line. Price backed by research: sets of 4 to 6 usually land between 6.99 and 11.99.

## Lens
- Lens (step 6): 5 photos, 2000x1600 JPEG via gs.save_jpeg. Grayson supplied REAL photos of empty frames (free Pexels photos) on Oct 19, 2026 and wants covers that look like the bestsellers: real frames in a real room. Query the mockups collection (approved true); each record has asset, name, kind, quads (frame openings in the photo's own pixels), slots, focus, and sometimes tag_y, pin_focus, pin_tag. Download each photo you use once with Artifact read (path = its asset id) and open it with PIL. wa.mockup_photo(photo, rec, designs, mpal=..., tag=..., sub=...) draws each design natively at its opening's shape, warps it in, keeps the photo's real light and shadow, warms the grade and crops to 2000x1600. Photos: (1) the cover: for a set of 6 use the gallery record (6 slots, one print per frame, best print top-left) with tag=[a 3 to 5 word title] and sub="Set of 6"; for sets of 4 or 5 use a single-frame wall record with the hero print and a 2-line tag; (2) wa.cover_set(prints, mpal, "6 PRINTS") so every print shows flat; (3) a different single-frame real photo with another print, no tag; (4) the hand record (square opening; the print is drawn square to fit; if the kit raises ValueError because the words do not fit, use another wall record instead); (5) wa.sizes_photo(best print, mpal). Rotate which wall photo leads from set to set so covers do not repeat. Save style.photoLayout "realphoto". NEVER draw a room, a wall, a sofa, a frame on a wall, a hand or any fake interior yourself: only these real photos may show rooms or hands. If the mockups collection is empty, fall back to wa.cover_flatlay for photos 1 and 3 and say so in the log.

## Inspect
- Atlas inspects (step 7): same rubric and pass mark (92). For wall art, file /25 means: every word spelled right, every verse matches the KJV source word for word with the right reference, every print drawn at 300 dpi in every size, page sizes correct, the PDF opens. Fail the slop check also if: a verse is misquoted or from a modern translation; any shape looks broken or smeared; any photo shows a drawn room, wall or hand; in a real-photo mockup the print does not sit exactly in the opening (gaps, overlap onto the frame, wrong angle) — check by reading a zoomed crop of each frame; the set looks like random unrelated prints; any brand, designer, character or film is suggested.

## Pixel
- Pixel (step 9): 2 or 3 pins per set, each 1000x1500, made with wa.mockup_photo(photo, rec, designs (a different hero print first each time), mpal=..., tag=[1 or 2 short lines], sub=a short line like "Printable set of 6", size=(1000, 1500), focus=rec["pin_focus"]) using records that have pin_focus, a different record per pin. Titles name the set and the search phrase, e.g. "Pink Bible Verse Wall Art Set: 6 Printable Christian Prints for a Girls Room". Save pin.style {layout "realphoto", desk (the record id), hero, kicker}. Use wa.pin_art only if no record has pin_focus.

## Variety
- Variety: no two wall art sets built back to back share the same art palette and background mix.

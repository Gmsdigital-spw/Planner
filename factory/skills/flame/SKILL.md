## Quality checklist
- Real numbers only. Nothing invented, nothing hidden.
- Looks like a top seller's work, not a template. Warm, real, clear.
- One thing measurably better than last run.
- The first line is under 8 words and names the buyer's result; the second lists what is inside from the copy's real page list or count, never an invented page (05-write Audit "Hooks"; docs.md per-channel rules).
- A caption with elevate, unlock, game-changer, an emoji wall, fake scarcity or an invented review fails before scoring (marketing-wing-v6.md rule 3; 05-write Audit "Banned words").
- The hook style alternates a number ("36 awards"), a question and a moment across days and uses the live price, never one from memory: Oct 22's 4 posts scored 93-95 on real counts (social/studio/README.md "Hook style", "Live price and title"; herald run log 10-22).
- A pin's top third carries the hook text in big type, and a video pin's text is a sentence with the link, never the bare listing link (cover-styles.md "Pins"; Oct 21 video pin 4597749137 refused by Pinterest for a bare listing link: video-pin run log 10-22).

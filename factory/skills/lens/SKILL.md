# Lens — Photos

## Job
Covers that make people want it (Grayson, Oct 21, 2026): bold theme color, the real product pages big, a count badge,
and the THING the product is about shown big as realistic 3D art (cookies on a cookie swap, Santa on Secret Santa,
a turkey on Thanksgiving, money on money planners). Build with tools/fun_covers.py (art in tools/img3d, see NOTICE.txt);
playbook: factory/playbooks/fun-listing-cover.md. Never beige-on-cream, never a cover without themed art.
REPLACING a cover = upload the new one at rank 1 AND delete the old one in the same run, then re-pull and check
there is exactly one 2000x1500 image.

## Exact steps (keep current; rewrite when a better way is proven)
1. Read this file and /factory/LESSONS.md before working.
2. Check the playbook for this task in /factory/playbooks/ and use it.
3. Do the work. Score it. Under 92 = redo, do not ship.
4. Log the result (score + the real number you're judged on).
5. Append one line to "What I've learned" below. "Same as yesterday" = fail.

## Quality checklist
- Real numbers only. Nothing invented, nothing hidden.
- Looks like a top seller's work, not a template. Warm, real, clear.
- One thing measurably better than last run.
